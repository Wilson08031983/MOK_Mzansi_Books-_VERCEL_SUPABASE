Sidebar Behavior Test

Test Info

This tool allows you to test the Auto-hide Sidebar setting for mobile devices.

It manipulates the same localStorage settings used by the app to control sidebar behavior.

Testing Instructions

To test on mobile:

  1. Open this page on a mobile device or use responsive mode in DevTools
  2. Toggle the setting to ON
  3. Open the main app in a new tab
  4. The sidebar should be hidden by default
  5. Trying to open the sidebar should not work while the setting is ON

Expected behavior:

  • When ON: Sidebar auto-hides and cannot be opened on mobile
  • When OFF: Sidebar behaves normally - can be opened and closed
